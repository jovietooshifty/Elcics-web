# Elcics web

Working repository for the **ELCICS Ltd.** website redesign (current site: <https://www.elcicsltdtt.com/>).

## What's here

| Folder | Contents |
| --- | --- |
| `docs/content-audit.md` | Full content audit and redesign plan: all site text by category, content weak points, missing pages, proposed sitemap, 9 project case studies + placeholders, client questions |
| `docs/proposed-sitemap.svg` / `.png` | Proposed sitemap diagram (6 menu sections, ~32 pages) |
| `docs/image-inventory.csv` | Every image on the current site: ID, page(s), section, current alt text, notes, original Wix URL |
| `docs/image-manifest.json` | Same inventory as JSON |
| `images/` | 89 original-resolution images from the current site, one folder per page (IDs match the inventory) |
| `brand/logo/` | Logo recreated as vector (SVG/PDF) in the exact 140 × 140 header framing, plus PNG exports up to 4480 px and an uncropped full-artwork version |
| `brand/colours/` | Brand colour palette: swatch sheet (PNG), CSS variables, JSON |
| `tools/` | Scripts used to trace the logo and build the palette sheet |
